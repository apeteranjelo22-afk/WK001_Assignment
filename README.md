
# Personal Budget and Expense Tracker

## Project Description

This project is a Personal Budget and Expense Tracker
developed using HTML and CSS.

The purpose of the project is to help users organize
and monitor their daily expenses.

## Project Files

### 1. index.html
This file contains the structure of the website.

It includes:
- Main heading and logo.
- Expense entry form.
- Category dropdown with five options.
- Expense table with five sample records.
- Budgeting video.
- Collapsible instructions.

### 2. style.css
This file controls the appearance of the website.

It includes:
- Page background and colors.
- Form styling.
- Table borders and alternating row colors.
- Button hover effects.
- Advanced CSS selectors.
- Responsive video styling.

### 3. README.md
This file explains the purpose of the project
and describes the different project files.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code

## Features

1. Expense entry form.
2. Five expense categories.
3. Expense table.
4. Budgeting video.
5. Collapsible instructions.
6. Interactive hover and focus effects.


# Personal Budget and Expense Tracker

## Project Description

This project is a Personal Budget and Expense Tracker
developed using HTML and CSS.

The application helps users organize and record their
daily expenses in a simple and user-friendly interface.

## Features

- Clean and professional visual design.
- Green and white color palette.
- Styled expense entry form.
- Organized expense table.
- Alternating table row colors.
- Rounded corners and consistent spacing.
- Google Fonts for improved typography.
- Responsive styling for smaller screens.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Visual Studio Code

## Project Files

- index.html: Contains the structure of the Budget Tracker.
- style.css: Controls colors, typography, spacing, forms,
  buttons, and table appearance.
- README.md: Explains the project and its features.

## What I Learned

Through this assignment, I improved my understanding
of CSS styling, color selection, typography, the CSS
Box Model, table styling, and responsive design.
